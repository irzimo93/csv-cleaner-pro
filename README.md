# CSV Cleaner Pro

A lightweight Python tool for cleaning CSV files and removing duplicate rows.

## Features
- Remove duplicate rows
- Remove completely empty rows
- Preserve the CSV header
- Support UTF-8 and UTF-8 with BOM
- No external libraries required

## Requirements
- Python 3

## Installation
Clone the repository from GitHub.

## Usage
python cleaner.py input.csv
python cleaner.py input.csv -o output.csv
