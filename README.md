# CSV Cleaner Pro

A lightweight Python command-line tool for cleaning CSV files.

## Features
- Remove duplicate rows
- Remove completely empty rows
- Trim unnecessary whitespace
- Preserve CSV headers
- Support UTF-8 and UTF-8 with BOM
- Process files row by row
- Display cleanup statistics
- Prevent input/output file conflicts
- No external dependencies

## Requirements
- Python 3.8 or newer

## Installation

```bash
git clone https://github.com/irzimo93/csv-cleaner-pro.git
cd csv-cleaner-pro
```

## Usage

```bash
python cleaner.py input.csv
python cleaner.py input.csv -o cleaned.csv
```
